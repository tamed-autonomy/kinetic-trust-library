# Security Policy

## Supported versions

`main` is the only currently maintained line. No Kinetic Trust Library package
release has been published yet, so there is no released-version support table.

## Reporting a vulnerability

Report suspected vulnerabilities privately to
[security@tamedautonomy.ai](mailto:security@tamedautonomy.ai). Do not disclose a
suspected vulnerability in a public GitHub issue, discussion, pull request, or
other public channel.

Include the affected revision, impact, reproduction information, and any known
mitigation when it is safe to do so. Reports are acknowledged and remediated on
a best-effort basis; this project does not promise a response or remediation
service-level agreement.

Passing tests, released vectors, package checks, or CodeQL is bounded evidence
about this Library. It is not evidence that a consuming product, deployment,
key lifecycle, evidence source, action, or enforcement path is secure or KTP
conformant.
